# MidnightRotation Listing Playbook

All rules live in `backend/seo.py`. Generation, approve-time SEO, `bulk_seo_update.py`,
`autopilot.py` and `create_products_from_designs.py` all use it.

## Titles
`[Primary keyword], [Secondary keyword] - [Design Name] | [Niche style]`

Example: `Oversized Goth Shirt, Burnt Chalice Graphic Tee - Ash Communion | Dark Industrial Alt Clothing`

- The first 3 words are a buyer search ("Oversized Goth Shirt", "Cyber Goth Shirt"), never the art name.
- The secondary keyword names the design's subject. At generation it comes from the theme
  ("Plague Gothic Graphic Tee"); at approve time Gemini picks one from the back concept.
- 140 characters max. Cyber themes use the cyber formulas.

## Tags (13, 20 characters max each)
1. Always: `Oversized Goth Shirt`, `Back Print Shirt`
2. Up to 5 design-specific tags. Each must name a product (`Plague Doctor Shirt`, `Glitch Saint Tee`).
   Prompt fragments (`Ash Cloud Graphic`, `Bone Soot Design`) are dropped automatically.
3. The rest come from the category's buyer-phrase pool (`Graphic Tee Men`, `Alt Clothing Men`,
   `Gothic Apparel`, `Industrial Music Tee`, ...).

Tags you edit by hand in the dashboard are kept as typed (only over-long ones and duplicates are dropped).

## Description
Keyword hook in sentence one, fit / print / material / sizing bullets, care instructions,
an "ABOUT THE DESIGN" AI-use disclosure, made-to-order note, favorite-the-shop CTA.
No fabric weights. Never says "typography".

Etsy (Oct 2026) requires disclosing AI-created items. The disclosure says the artwork was made
with AI-assisted tools and finalized by hand, and that the photos are mockups of the exact
print. If a listing also shows an AI scene photo, it says that photo is an AI illustration.

## Photos: 4-photo checklist
| Rank | Photo | Source |
|------|-------|--------|
| 1 | Back print (primary thumbnail) | Printify back mockup, moved to rank 1 automatically |
| 2 | Front left-chest close-up | Printify front mockup |
| 3 | Size chart | One reusable Gildan 5000 size chart image, added by hand on Etsy |
| 4 | Lifestyle (optional, off by default) | Generated by `generate_mockups.py`, uploaded at rank 4 |

AI lifestyle photos are **off by default** (Settings → Etsy Listings). Under Etsy's Oct 2026
rules a buyer can claim the shirt looks different from an AI photo, and the refund is on you.
If turned on: high contrast, light-to-mid grey backdrop, the black shirt fills at least 80% of
the frame, theme only hinted at the edges. No dark-on-dark scenes.

Approve every design yourself. Etsy removes listings made by bots with no human involvement
and may close the shop.

## Fixing the existing catalog
Easiest: dashboard → Settings → Etsy Listings → **Test on 1 listing**, check it on Etsy, then
**Fix all listings**. It rewrites title, tags and description (with the disclosure) for every
Printify product, re-syncs only the text to Etsy, and moves old AI photos from rank 1 to rank 4.

Or run the scripts locally (dry run first):
```
# 1. Titles, tags, descriptions (--publish syncs text to Etsy; photos are not touched)
python bulk_seo_update.py --product-id <PRINTIFY_ID>          # preview one
python bulk_seo_update.py --product-id <PRINTIFY_ID> --apply --publish  # apply one + sync to Etsy, check it
python bulk_seo_update.py --apply --publish                   # everything

# 2. Photo order on live Etsy listings (old atmospheric photo rank 1 -> rank 4)
python reorder_listing_photos.py --listing-id <ETSY_LISTING_ID>          # preview one
python reorder_listing_photos.py --listing-id <ETSY_LISTING_ID> --apply
python reorder_listing_photos.py --apply
```
